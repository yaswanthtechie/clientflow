# User Flow

1. Register an account or sign in.
2. Create a client with an hourly rate.
3. Create a project and tasks for that client.
4. Add billable time entries against tasks.
5. Select unbilled time entries and generate a draft invoice.
6. Mark the invoice sent and later paid.
7. Review dashboard totals and outstanding invoices.

Failure states to design: invalid credentials, invalid data, unauthorized access, no billable time, duplicate billing attempt, and invalid invoice status transition.
